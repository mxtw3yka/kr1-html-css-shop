# Учебный frontend-проект

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема проекта: многостраничный сайт интернет-магазина или каталога услуг.

## Структура проекта

```
kr1-html-css-shop/
├── index.html      — главная страница;
├── catalog.html    — каталог товаров;
├── product.html    — карточка товара;
├── order.html      — оформление заявки;
├── contacts.html   — контакты;
├── css/
│   └── style.css   — общий файл стилей;
├── js/
│   └── main.js     — JavaScript (модальное окно и валидация формы);
├── images/         — папка для изображений;
├── sitemap.xml     — карта сайта;
├── README.md       — описание проекта;
└── .gitignore      — список файлов, исключённых из Git.
```

## Контрольная работа №1

Тема: «HTML и CSS: разработка многостраничного сайта».

В проекте реализован многостраничный HTML/CSS-сайт интернет-магазина
без CSS-фреймворков. Основная задача — показать владение HTML, CSS,
семантической разметкой, многостраничной структурой, формами, модальным
окном, навигацией, Flex/Grid и методологией БЭМ.

## Страницы проекта

- `index.html` — первый экран (hero-блок), преимущества, популярные товары;
- `catalog.html` — сетка карточек товаров и статические фильтры;
- `product.html` — карточка товара: изображение, описание, характеристики (таблица), цена, кнопка заявки;
- `order.html` — отдельная страница с формой оформления заявки;
- `contacts.html` — контактная информация и ссылка на форму заявки.

## Инструкция по просмотру проекта

## Именование классов по БЭМ

Разметка разделена на блоки, элементы и модификаторы:

- блок — самостоятельный компонент: `site-header`, `site-nav`, `breadcrumbs`, `hero`, `section`, `products-grid`, `product-card`, `product-detail`, `product-table`, `catalog-layout`, `catalog-filters`, `order-dialog`, `order-form`, `button`, `site-footer`;
- элемент — часть блока, двойное подчёркивание: `site-header__logo`, `site-nav__link`, `product-card__title`, `product-card__badge`, `product-detail__image`, `order-form__input`, `catalog-filters__form`, `breadcrumbs__link`;
- модификатор — изменение вида, двойной дефис: `site-nav__link--active`, `product-card--featured`, `product-card--discount`, `product-card__badge--new`, `product-card__badge--hit`, `order-form--page`, `button--primary`, `button--secondary`.

Общие «плавающие» имена вроде `form-field`, `site-logo` и `filters-form` убраны: каждый класс теперь принадлежит конкретному блоку, поэтому его нельзя случайно применить к чужому элементу. Разметка и стили обращаются к классам, стилизация через `id` и inline-стили не используются. Единственное исключение — однотипные ячейки таблицы характеристик, для которых используются селекторы `.product-table th` и `.product-table td`.

## Базовое позиционирование

Используются базовые значения `position` и `z-index`:

- `position: sticky` + `z-index: 10` — шапка остаётся у верхней границы окна при прокрутке;
- `position: sticky` + `align-self: start` — блок фильтров в каталоге прижат к низу шапки (`align-self` обязателен, иначе Grid растянет элемент и прилипание не сработает);
- `position: relative` — карточка товара и блок изображения на странице товара как базовая точка отсчёта;
- `position: absolute` + `z-index: 1` — бейдж карточки («Новинка», «Скидка», «Хит») внутри карточки;
- `position: fixed` + `z-index: 20` — сообщение об успешной отправке поверх страницы;
- `position: fixed` + `z-index: 15` — кнопка «Наверх», скрытая через `display: none` и показываемая модификатором `.to-top--visible` после прокрутки более чем на 300 px.

На узких экранах (`@media (max-width: 900px)` и `max-width: 600px`) прилипание
фильтров отключается, макет каталога и страница товара перестраиваются в одну
колонку, а сетка карточек — в две и одну колонку соответственно.

## Использование Flexbox и Grid

В проекте используются:

- Flexbox для основного меню;
- Flexbox для внутренней структуры карточек товаров и блока кнопок;
- CSS Grid для сетки карточек;
- CSS Grid для страницы каталога с фильтрами и списком товаров;
- CSS Grid для страницы товара (изображение и информация).

## Навигация и якорные ссылки

- общее меню в шапке связывает все страницы: `index.html`, `catalog.html`, `product.html`, `order.html`, `contacts.html`;
- якорные ссылки на главной странице: `index.html#advantages`, `index.html#popular`;
- активный раздел меню выделяется модификатором `site-nav__link--active`.
