## Именование классов по БЭМ

Разметка разделена на блоки, элементы и модификаторы:

- блок — самостоятельный компонент: `site-header`, `site-nav`, `product-card`, `order-form`, `catalog`, `breadcrumbs`, `hero`, `button`;
- элемент — часть блока, двойное подчёркивание: `site-header__logo`, `product-card__title`, `order-form__control`, `catalog__filters-form`, `breadcrumbs__link`;
- модификатор — изменение вида, одинарное подчёркивание с дефисом: `order-form__field--checkbox`.

Общие «плавающие» имена вроде `form-field`, `site-logo` и `filters-form` убраны: каждый класс теперь принадлежит конкретному блоку, поэтому его нельзя случайно применить к чужому элементу. Стили в `css/style.css` обращаются только к классам, селекторы по тегам внутри блоков убраны.

## Базовое позиционирование

Используются базовые значения `position` и `z-index`:

- `position: sticky` + `z-index: 10` — шапка остаётся у верхней границы окна при прокрутке;
- `position: sticky` + `align-self: start` — блок фильтров в каталоге прижат к низу шапки (`align-self` обязателен, иначе Grid растянет элемент и прилипание не сработает);
- `position: relative` — карточка товара как базовая точка отсчёта для элементов внутри неё;
- `position: fixed` + `z-index: 20` — сообщение об успешной отправке поверх страницы;
- `position: fixed` + `z-index: 15` — кнопка «Наверх», скрытая через `display: none` и показываемая модификатором `.to-top--visible` после прокрутки более чем на 300 px.

На узких экранах (`@media (max-width: 900px)`) прилипание фильтров отключается, чтобы блок не перекрывал содержимое.
