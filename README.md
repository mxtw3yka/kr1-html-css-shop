# Gear

Gear — многостраничный каталог электроники на React: 11 товаров и услуг, включая клавиатуры, мыши, наушники, ноутбуки, настройку оборудования и сопровождение.

## Запуск

Требуется Node.js 20.19+ или 22.12+.

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite. Для сборки выполните `npm run build`: готовые страницы появятся в `dist/`. Открывать HTML-страницы напрямую через `file://` нельзя — они загружают React через Vite.

## Страницы

- `index.html` — главная, популярные товары и форма проверки данных в модальном окне;
- `catalog.html` — каталог с работающими фильтрами и сортировкой;
- `product.html?id=k-200` — карточка товара; у K-200 есть галерея, характеристики и условия доставки. Без параметра `id` открывается K-200;
- `order.html` — форма проверки данных, выбранный товар передаётся через `?product=`;
- `contacts.html` — контакты и информация об онлайн-магазине;
- `search.html` — поиск по товарам и услугам;
- `cabinet.html` — локальное избранное без регистрации.

На всех страницах есть общие шапка и футер. Оформление Gear выдержано в серо-графитовой гамме с металлическими акцентами; используются логотип-шестерёнка, курсор и кнопка «Наверх».

## Возможности

- Светлая и тёмная тема с анимированным переключением; по умолчанию тёмная. При уменьшенном движении анимация отключается.
- Поиск по названию, описанию и категории, включая написание `е`/`ё`.
- Избранное хранится только в `localStorage` этого браузера. Это не аккаунт и не синхронизация.
- Курсор в форме гаечного ключа показывается на устройствах с точным указателем; поля ввода сохраняют текстовый курсор.
- Адаптивное меню, кнопка «Наверх» со значком гаечного ключа, карта Москвы в футере и кнопки поиска соцсетей.
- Фильтры каталога по категории, подборке, цене и наличию, сортировка по цене и новизне.
- Форма проверяет поля в браузере и показывает результат проверки. **Данные не отправляются и не сохраняются; заказ не создаётся.**

## Структура и медиа

- `src/main.jsx` — выбор страницы и локальное состояние темы и избранного;
- `src/components/` — общая оболочка и карточка товара;
- `src/pages/` — содержимое страниц;
- `src/data/products.js` — единый каталог из 11 позиций;
- `src/styles/` — оформление страниц и тем;
- `public/favicon.svg` — знак Gear для вкладки браузера;
- `images/products/` — локальные фотографии. Источники, авторы и лицензии указаны в [`images/products/CREDITS.md`](images/products/CREDITS.md).

## Публикация

Изменения в `main` собираются GitHub Actions из исходников React/Vite и публикуются из `dist/` на [GitHub Pages](https://mxtw3yka.github.io/kr1-html-css-shop/). Настройка Pages должна использовать источник GitHub Actions, а не файлы из корня ветки.
